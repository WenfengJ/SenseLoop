# Demo 链接与运行方式

## 当前本地 Demo

前端：

```text
http://127.0.0.1:5173/
```

后台：

```text
http://127.0.0.1:8000/
```

后台健康检查：

```text
http://127.0.0.1:8000/health
```

## 快速启动

只启动前端：

```bash
bash scripts/start-frontend.sh
```

只启动后台：

```bash
bash scripts/start-backend.sh
```

同时启动前后端：

```bash
bash scripts/start-all.sh
```
