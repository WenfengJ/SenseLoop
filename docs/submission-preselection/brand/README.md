# 品牌视觉提交材料

这个目录放正式提交时可以直接使用的 Logo 和项目封面图。

## 文件

- `senseloop-logo.svg`：项目 Logo。
- `senseloop-cover.svg`：项目封面图，可用于 PPT 首页、视频封面、项目概览。

## 当前版本风格

- 清透健康科技感。
- 薄荷绿 + 晨光珊瑚色。
- 视觉概念：声音波纹 + 生命节律 + 每日健康闭环。

## 使用建议

- README 顶部：使用 Logo。
- PPT 首页：使用封面图。
- 3 分钟演示视频封面：使用封面图。
- 一页式 PDF：使用封面图或 Logo。
