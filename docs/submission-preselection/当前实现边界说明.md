# 当前实现边界说明

## 已真实实现

- 前端 HTML Demo。
- 六个页面：首页、睡眠页、饮食页、信号页、日报页、技术架构页。
- 五类用户画像切换。
- 本地 mock 数据。
- 本地规则引擎生成每日报告。
- 睡眠页细节增强：整夜声音地图、事件分类统计、录音片段回看、模拟播放按钮、分贝/时长/置信度/来源标签。
- Python 后台骨架。
- 零依赖 Python 后台。
- 快速启动脚本。
- 项目 README 和文档索引。

## 当前使用模拟数据

- 夜间声音事件。
- 打鼾、咳嗽、翻身、起夜、环境噪声标签。
- 录音片段波形、分贝值、7 天声音趋势和整夜噪声地图。
- 饮食 kcal 估算。
- 排便状态。
- 舌苔状态。
- 口气反馈。
- 心率、步数、运动时间。

- 将真实声音事件转换为 `SleepAudioEvent`。
- 用真实录音替换当前录音片段列表、噪声地图、分贝和置信度展示。
- 将重点标记进入每日报告。
- 增加音频上传和图片上传。
- 接入 LLM 生成更自然的报告文案。
