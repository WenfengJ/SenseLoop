# 演示视频

这里放预选提交用的演示视频。

建议文件名：

```text
anker-SenseLoop-3分钟演示.mp4
```

视频要求建议：

- 3 分钟以内。
- 1080p 屏幕录制。
- 开场先讲 Anker 录音笔 / soundcore Work 记录夜间声音。
- 明确这是 MVP：先跑通“睡眠声音闻诊主线 + 舌苔/排便/资料补充 + 中医知识库解释 + 个人健康助手”的闭环。
- 演示主流程：今日页 -> 检测页 -> 舌诊/资料上传 -> 问诊助手 -> 报告 -> 我的/邮箱验证码登录。
- 重点展示录音笔声音数据如何进入今日建议、问诊助手和报告沉淀。
- 舌苔、大便、饮食和体检资料不要单独讲成散点功能，要说它们都是围绕望闻问切补齐用户健康上下文。
- 录制前确认线上后端健康检查返回 `dbReady: true`。

当前需要人工操作：

1. 按 `../3分钟演示视频脚本.md` 录屏。
2. 上传到官方要求的平台或网盘。
3. 将链接填写到 `../submission-ready/人工填写项.md`。
