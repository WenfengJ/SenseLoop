## 当前赛场要求与任务宗旨

官方预赛材料以轻量化为主，不要求完整立项文档，但必须让评审快速理解：

- 选择了什么赛道。
- 理解了什么真实业务/用户痛点。
- 方案做什么、怎么做、为什么这样做。
- AI 在其中发挥什么具体作用。
- 24 小时内能做出什么可演示原型。
- 团队是否具备实现能力。

SenseLoop 的参赛宗旨：

```text
智能录音赛道
  -> soundcore Work 夜间声音作为闻诊入口
  -> 岐黄问诊助手作为产品中心
  -> 望闻问切四诊 Agent 工作流
  -> 中医知识库/RAG 解释依据
  -> 个人健康建议、追问、报告和长期记忆
```

飞书材料重点讲 2-3 个核心功能：

1. soundcore 夜间声音闻诊：鼾声、咳嗽、夜醒、起夜、环境噪声进入健康档案。
2. 岐黄问诊助手：结合当前档案、睡眠声音、舌苔/排便/报告摘要和知识库继续追问。
3. 四诊报告沉淀：把检测和问诊结果沉淀为报告、趋势和下一步建议。
