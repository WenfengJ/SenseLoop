# 提交准备

这个目录统一存放正式提交前需要人工确认和逐项检查的内容。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `人工填写项.md` | 记录必须由参赛者人工补充的信息，例如队伍信息、官方赛道、演示视频链接、SDK/API Key 状态 |
| `提交前检查表.md` | 正式提交前逐项打勾，确认 README、Demo、代码、文档、PPT/PDF、隐私边界等是否准备完整 |

## 使用方式

1. 先补 `人工填写项.md` 里无法自动确认的信息。
2. 再按 `提交前检查表.md` 逐项核对。
3. 提交前最后检查 `../TODO-参赛提交补充清单.md`，确认没有 P0 遗漏项。
