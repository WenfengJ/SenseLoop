## 设计概念

Logo 由三个元素组成：

- 声音波纹：对应 soundcore Work 的夜间声音入口。
- 生命节律线：对应身体信号、睡眠和恢复状态。
- 环形闭环：对应“夜间声音 -> 身体理解 -> 晨间建议”的产品闭环。
