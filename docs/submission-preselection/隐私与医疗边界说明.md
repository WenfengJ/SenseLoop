# 隐私与医疗边界说明

## 产品边界

SenseLoop 是健康趋势观察和生活方式建议产品，不是医疗诊断产品。

不会承诺：

- 诊断疾病。
- 治疗疾病。
- 判断具体病因。
- 输出医疗处方。
- 替代医生。

## 声音数据

原则：

- 原始夜间音频优先本地处理。
- 当前 Demo 保存的是结构化事件标签。
- 报告使用打鼾、咳嗽、起夜、环境噪声等摘要，不直接依赖原始音频。

表达边界：

- 可以说“打鼾片段较多，建议继续观察”。
- 不说“你患有睡眠呼吸暂停”。

## 排便数据

原则：

- 必须用户主动记录。
- 不做自动拍摄。
- 不用 eufy 拍摄厕所或大便。
- 默认保存标签，不保存原图。

表达边界：

- 可以说“排便偏干，建议补水和膳食纤维”。
- 不说“你患有某种肠胃疾病”。

## 舌苔与口气

原则：

- 舌苔拍照必须用户主动触发。
- 口气当前使用手动反馈或未来传感器。
- 只做趋势观察和生活建议。

表达边界：

- 可以说“舌苔偏厚，建议减少油腻并结合睡眠继续观察”。
- 不说“你有某种疾病”。

## eufy 视觉能力

eufy 只用于非隐私视觉场景：

- 饮食记录。
- 老人夜间活动。
- 生活状态观察。

不用于：

- 厕所。
- 大便。
- 身体隐私部位。
- 未授权的家庭监控。

## 家庭共享

老人关怀场景中，家人端只展示摘要和趋势：

- 夜间起身次数。
- 咳嗽趋势。
- 睡眠状态。
- 建议关注。

不展示过度私密细节。

## 评审答辩表达

推荐表达：

> SenseLoop 不做医疗诊断，只做日常身体趋势观察、异常提醒和生活方式建议。涉及排便、舌苔、口气等敏感信号时，必须由用户主动触发，默认保存结构化标签而不是原始隐私内容。连续异常时，产品只提示继续观察或咨询专业医生。
