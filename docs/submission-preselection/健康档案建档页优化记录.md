# 健康档案建档页优化记录

## 本次新增页面

新增 `建档` 页面，作为 SenseLoop 的第一入口。

页面定位：

> 用户先通过基础问答、拍照信号和夜间录音完成健康档案，再生成第一份 AI 健康日报。

它强化 SenseLoop 不是单纯睡眠 App，而是基于“望闻问切”的 AI 健康助手。

## 前端优化点

- 将默认首页调整为 `建档`，让用户第一眼看到产品核心：先建档，再生成健康建议。
- 将静态说明改成可点击的建档流程：基础信息、照片数据源、录音数据源、四诊模块和报告生成按钮都可以交互。
- 新增手机式建档预览：更接近参考图里的注册/健康报告 App 视觉，而不是单纯网页展示。
- 新增建档完成度联动：选择更多照片、录音事件并生成报告后，完成度会实时变化。
- 新增基础信息选择器：年龄、当前目标、生活方式、晨间感受均可切换，并改变健康日报预览文案。
- 新增照片数据源列表：
  - 早餐照片：识别饮食结构。
  - 舌苔照片：提示照片质量和待确认状态。
  - 排便记录：沉淀敏感信号标签。
- 新增录音数据源列表：
  - 打鼾片段。
  - 咳嗽片段。
  - 环境噪声。
  - 每一项都可以选择是否进入报告。
- 新增“望 / 闻 / 问 / 切”模块切换：点击不同模块后，下方说明和操作按钮会切换。
- 新增首份报告生成状态：点击“生成健康报告”后，手机预览会从“等待生成”切换为“报告已生成”。
- 页面视觉沿用当前绿色、青色、暖黄主题，避免和现有页面割裂。

## MVP 产品亮点

### 1. 建档不是表单，而是健康报告入口

用户每点一个选项，都会影响建档完成度和报告预览。这让 MVP 可以讲清楚：

```text
用户注册/建档 -> 数据源选择 -> 信号标签 -> 健康日报
```

### 2. 用望闻问切组织多数据源

MVP 不只展示单一睡眠数据，而是把日常健康输入组织成四类：

- 录音数据源：打鼾、咳嗽、起夜、环境噪声、重点标记。
- 拍照数据源：饮食、舌苔、排便状态。
- 用户基础信息：年龄、性别、职业、目标、晨间感受。
- 未来体征数据：心率、血氧、运动、睡眠体征。

### 3. 建档后直接生成行动建议

用户不是为了填表而填表。建档后的结果会直接进入日报：

- 今天怎么吃。
- 今天怎么动。
- 今天怎么恢复。
- 哪些异常需要继续观察。

### 4. 当前能跑通，未来可扩展

当前比赛 MVP 聚焦：

```text
用户建档 -> 录音/拍照/问答标签 -> 健康报告 -> 今日行动建议
```

未来硬件演进：

```text
soundcore Work 原型 -> SenseLoop Watch / Band / Pendant
```

### 5. 隐私边界清楚

敏感输入不默认上传原始内容：

- 音频优先沉淀为事件标签。
- 图片优先沉淀为趋势标签。
- 排便、舌苔、口气等敏感数据必须用户主动触发。
- 输出定位为趋势观察和生活方式建议，不做医疗诊断。

## 建议对外表达

推荐一句话：

> SenseLoop 用“望闻问切”重构健康建档：通过录音、拍照和用户基础信息，把日常身体信号转成每天能执行的健康建议。

推荐比赛口径：

> 当前 MVP 先跑通“建档 -> 信号标签 -> 每日健康报告”的闭环；未来再由 Watch / Band / Pendant 承接更多体征数据。
