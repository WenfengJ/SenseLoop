## 推荐二维码内容

二维码建议直接指向在线 Demo 首页：

```text
https://你的-demo-地址/
```

如果最终没有在线 Demo，也可以退而求其次指向 GitHub 仓库：

```text
https://github.com/你的账号/anker-SenseLoop
```

## 生成方式

可以使用任意二维码工具生成。

推荐方式：

1. 部署前端 Demo。
2. 复制公开链接。
3. 使用二维码生成工具生成 PNG。
4. 保存到本目录。
5. 在 PPT / PDF 的最后一页放入二维码。

## PPT 使用建议

建议放在：

- PPT 首页右下角。
- Demo 展示页右下角。
- 最后一页“扫码体验 Demo”。

旁边配文：

```text
扫码体验 SenseLoop Demo
```
