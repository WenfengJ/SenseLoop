# 3 分钟演示视频脚本

## 视频目标

视频要让审核者在 3 分钟内看懂：

- 真实问题是什么。
- 使用了哪个 Anker 硬件。
- 当前 Demo 如何跑通核心闭环。
- 为什么它不是普通睡眠 App。
- 未来如何演进成健康穿戴产品。

## 0:00-0:25 真实痛点

口播：

> 很多人每天都会收到身体发出的信号：睡醒还是累，夜里打鼾咳嗽，排便不顺，口气变重，舌苔变化，减脂期间状态波动。但这些信号分散在不同地方，普通用户很难判断它们之间有什么关系，也不知道今天应该怎么调整。

画面：

- 展示首页。
- 展示今日健康状态和今日建议。

## 0:25-0:50 产品一句话

口播：

> 观息 SenseLoop 是一款基于 soundcore Work 夜间声音入口的 AI 健康行动助手。它不只是告诉用户昨晚发生了什么，而是在早晨生成今天怎么吃、怎么动、怎么恢复、哪些异常需要继续观察的个性化建议。

画面：

- 展示项目名。
- 展示五类用户画像。

## 0:50-1:35 Demo 主流程

口播：

> 这里选择减脂用户。首页先给出今日状态和恢复分。昨晚恢复不足，所以今天不建议硬扛高强度训练。进入睡眠页，可以看到 soundcore Work 夜间声音事件，包括翻身、咳嗽和打鼾。进入日报页，系统把夜间声音、饮食、排便、舌苔和口气这些信号，转成今天的饮食、运动和恢复建议。

画面：

- 切换用户画像。
- 点击睡眠页。
- 展示夜间声音时间线。
- 点击日报页。
- 展示建议卡片。

## 1:35-2:10 差异化

口播：

> 普通睡眠 App 通常停在睡眠分数和打鼾记录。SenseLoop 的不同点是，它把夜间声音和用户画像、饮食、排便、舌苔、口气结合起来，形成第二天的行动建议。用户真正需要的不是多一个分数，而是今天该怎么做。

画面：

- 展示饮食页。
- 展示信号页。
- 展示四诊完成度。

## 2:10-2:35 技术路线

口播：

> 技术上，我们把 soundcore Work、App 输入和未来 eufy 事件统一转成结构化标签，再通过健康知识库和规则引擎生成每日报告。真实 SDK、音频模型、图像模型和 LLM 都通过 adapter 预留。没有 SDK 或 API Key 时，Demo 仍然可以本地运行。

画面：

- 展示技术架构页。
- 展示 README 或代码目录。

## 2:35-3:00 未来演进

口播：

> 当前版本用 soundcore Work 验证夜间声音到健康建议的闭环。未来它可以演进为 SenseLoop Watch、Band 或 Pendant，把声音、图像、心率、脉搏、血氧、口气等信号集成进新的健康穿戴产品，成为 Anker 健康穿戴方向的新品类探索。

画面：

- 展示架构页未来硬件。
- 结束在首页或项目名。
