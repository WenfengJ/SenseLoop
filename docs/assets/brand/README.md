# SenseLoop 品牌视觉

## 设计方向

SenseLoop 的视觉核心是：

```text
声音波纹 + 生命节律 + 每日健康闭环
```

Logo 不走医院风，也不走玄学风，而是偏“清透健康科技 + 早晨恢复感”。

## 视觉关键词

- 夜间声音。
- 身体信号。
- 晨间行动建议。
- 闭环。
- 健康穿戴。
- 隐私可信。

## 主色

- 清透薄荷绿：`#41BFA6`
- 深海青：`#123B3A`
- 晨雾白：`#F7FBF8`
- 晨光珊瑚：`#FFB36B`
- 浅水蓝：`#DDF5F1`
