# Task 12：HTML Demo 页面实现

## 1. 本任务结论

HTML Demo 第一版已经实现六个核心页面：

- 首页。
- 睡眠页。
- 饮食页。
- 信号页。
- 日报页。
- 技术架构页。

当前版本已经能跑通：

```text
用户画像切换
  -> mock 身体数据
  -> 规则引擎生成日报
  -> 页面展示今日建议
  -> 睡眠、饮食、身体信号、架构分页面演示
```

## 2. 已实现页面

### 首页

展示：

- 今日健康状态。
- 恢复分。
- 睡眠时长。
- 夜间声音事件数量。
- 四诊完成度。
- 今日三件事：怎么吃、怎么动、怎么恢复。

### 睡眠页

展示：

- soundcore Work 夜间声音定位。
- 打鼾片段。
- 咳嗽片段。
- 重点标记。
- 夜间声音时间线。
- 近 7 天趋势。

### 饮食页

展示：

- 今日 kcal 建议区间。
- 已记录 kcal。
- 餐食模拟识别结果。
- kcal 区间估算。
- 饮食标签。
- 拍照记录入口。

### 信号页

展示：

- 排便记录。
- 舌苔观察。
- 口气反馈。
- 隐私策略。
- 手动触发入口。

### 日报页

展示：

- 每日健康建议标题。
- 夜间声音摘要。
- 身体状态提示。
- 今日饮食建议。
- 今日运动/恢复建议。
- 异常趋势提醒。

### 技术架构页

展示：

- 当前原型：soundcore Work。
- App 补充：用户画像和身体信号。
- 知识库与规则。
- 未来硬件：手表、手环、项链。
- 当前可演示与现场可增强能力。

## 3. 已实现交互

- 五类用户画像切换。
- 底部导航切换页面。
- 顶部架构入口。
- 不同用户画像生成不同报告重点。

## 4. 已验证

- `npm run build` 构建通过。
- 本地服务已启动。
- 浏览器验证首页渲染正常。
- 浏览器验证睡眠、饮食、信号页可正常切换。

## 5. 当前边界

当前仍然是 Demo 第一版：

- 不接真实 soundcore Work SDK。
- 不接真实 eufy SDK。
- 不调用真实 API Key。
- 不做真实音频识别。
- 不做真实图片识别。

这些能力都已经通过 adapter 和数据结构预留。
