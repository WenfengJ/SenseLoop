## 服务器目录

```bash

```

当前结构：

```text
/opt/senseloop/
  frontend/              # 前端 dist 构建产物
  backend/               # Python 后台代码
  logs/

  frontend.Dockerfile
  backend.Dockerfile
```


说明：

- 服务器原本已有 `alluxio_nginx` 占用 80/443。
- SenseLoop 不直接占用公网端口。
- 通过现有 nginx 增加 `/senseloop/` 和 `/senseloop-api/` 路径转发。

## Nginx 配置

宿主机配置文件：

```bash
/opt/alluxio-registry/nginx/default.conf
```

已新增 location：

```nginx
location ^~ /senseloop-api/ {
    proxy_pass http://senseloop_backend:8000/;
}

location ^~ /senseloop/ {
    proxy_pass http://senseloop_frontend/;
}
```

查看配置：

```bash
cat /opt/alluxio-registry/nginx/default.conf
```

测试 nginx 配置：

```bash
docker exec alluxio_nginx nginx -t
```

重启 nginx：

```bash
docker restart alluxio_nginx
```

## 重新部署前端

本地构建：

```bash
npm run build -- --base=/senseloop/
```

本地打包上传：

```bash
rm -rf /tmp/senseloop-deploy
mkdir -p /tmp/senseloop-deploy/frontend
cp -R dist/* /tmp/senseloop-deploy/frontend/
tar -C /tmp -czf /tmp/senseloop-frontend.tar.gz senseloop-deploy
scp /tmp/senseloop-frontend.tar.gz root@13.57.166.217:/tmp/senseloop-frontend.tar.gz
```

服务器更新：

```bash
ssh root@13.57.166.217
mkdir -p /opt/senseloop
tar -xzf /tmp/senseloop-frontend.tar.gz -C /opt/senseloop --strip-components=1
cd /opt/senseloop
docker build -t senseloop-frontend:latest -f frontend.Dockerfile .
docker rm -f senseloop_frontend
docker run -d \
  --name senseloop_frontend \
  --restart unless-stopped \
  --network alluxio-registry_default \
  -v /opt/senseloop/logs/frontend:/var/log/nginx \
  --log-driver json-file \
  --log-opt max-size=10m \
  --log-opt max-file=5 \
  senseloop-frontend:latest
```

## 重新部署后台

本地打包上传：

```bash
rm -rf /tmp/senseloop-backend-update
mkdir -p /tmp/senseloop-backend-update/backend
rsync -a --delete backend/ /tmp/senseloop-backend-update/backend/
tar -C /tmp -czf /tmp/senseloop-backend-update.tar.gz senseloop-backend-update
scp /tmp/senseloop-backend-update.tar.gz root@13.57.166.217:/tmp/senseloop-backend-update.tar.gz
```

服务器更新：

```bash
ssh root@13.57.166.217
mkdir -p /opt/senseloop/logs/backend
cd /opt/senseloop
mv backend "backend.bak.$(date +%Y%m%d-%H%M%S)" 2>/dev/null || true
tar -xzf /tmp/senseloop-backend-update.tar.gz -C /opt/senseloop --strip-components=1
docker build -t senseloop-backend:latest -f backend.Dockerfile .
docker rm -f senseloop_backend
docker run -d \
  --name senseloop_backend \
  --restart unless-stopped \
  --network alluxio-registry_default \
  -e HOST=0.0.0.0 \
  -e PORT=8000 \
  -v /opt/senseloop/logs/backend:/logs \
  --log-driver json-file \
  --log-opt max-size=10m \
  --log-opt max-file=5 \
  senseloop-backend:latest
```

## 注意事项

- 不要直接覆盖服务器原有 `/` 站点。
- 不要停掉 `alluxio_*` 容器，除非明确知道影响。
- SenseLoop 当前挂在 `/senseloop/` 子路径。
- 前端构建必须使用 `--base=/senseloop/`，否则静态资源路径会错。
- 后台容器必须使用 `HOST=0.0.0.0`，否则 nginx 容器访问不到后台服务。
